# Space Age music without Space Age

**To make this mod work, you'll need to copy or link the music files from your space age folder:**

## Linux

From the root folder of this mod, create a symlink to the space-age music folder:
`rm -r space-age-sound-ambient-folder && ln -s <factorio folder>/data/space-age/sound/ambient space-age-sound-ambient-folder`
(Replace `<factorio folder>` with the path to your factorio folder)

## Windows

Copy the entire contents of the `<factorio folder>/data/space-age/sound/ambient` folder into this mod's `space-age-sound-ambient-folder` folder.
