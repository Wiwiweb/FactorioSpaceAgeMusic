**To make this mod work, you'll need to copy or link the music files from your space age folder, into this folder:**

## Linux

1) Go down to the root folder of this mod.
2) Create a symlink to the space-age music folder: (Replace <factorio folder> with the path to your factorio folder)
`rm -r space-age-sound-ambient-folder && ln -s <factorio folder>/data/space-age/sound/ambient space-age-sound-ambient-folder`

## Windows

Copy the entire contents of the `<factorio folder>/data/space-age/sound/ambient` folder into this folder (`space-age-sound-ambient-folder`).
